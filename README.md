# Saniya & Hasnain — Rukhsati Invitation

A mobile-first Next.js App Router invitation for Saniya Nadeem Sayyed and Hasnain Furqan Saifi.

## Stack
- Next.js App Router
- React 19
- TypeScript
- CSS
- Static assets in `public/`

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

The project is designed for static-style deployment on Vercel or another Node-compatible Next.js host.

## Main structure

- `app/page.tsx` — page entry
- `app/layout.tsx` — metadata and viewport
- `app/invitation.css` — invitation design system and responsive styles
- `components/Invitation.tsx` — interactive invitation experience
- `public/assets/photos/` — three supplied memories
- `public/assets/audio/` — supplied Nasheed
- `public/assets/geometry/` — Islamic geometry assets
